# Best Keyboard ⌨️

Teclado nativo para Android (Kotlin), rápido y sin internet.
Developer: **Luisell Peña Rodríguez**

## 📥 Descargar (siempre la última versión)

👉 https://github.com/Brody5xx/Teclado/releases/download/ultima-version/BestKeyboard.apk

Cada cambio que se sube a este repositorio se construye solo con GitHub Actions
y reemplaza el archivo de ese enlace (tarda unos 4-6 minutos).

## Instalar
1. Abre el enlace en el teléfono y descarga `BestKeyboard.apk`.
2. Ábrelo e instala (si Android lo pide, permite "instalar apps desconocidas").
3. Abre **Best Keyboard** y sigue los 2 pasos de la pantalla.

Las versiones nuevas se instalan encima de la anterior sin perder tus ajustes.

## Créditos
Diccionarios de frecuencia: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) de Hermit Dave
(subtítulos de OpenSubtitles 2018), licencia CC-BY-SA 4.0. Se generan con `tools/make_dicts.py`.
